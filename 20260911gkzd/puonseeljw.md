# 强烈建议揭阳试管婴儿中夫妻双方减肥！

> 更新时间：2026-09-11 (UTC+8)

俗话说，一白遮三丑，一胖毁所有。其实肥胖除了对女性外貌体型产生影响以外，还有许多危害，例如肥胖易引起女性月经异常和不孕，肥胖女性易患乳腺癌、卵巢癌和子宫内膜癌等等。什么情况叫做“肥胖”呢？

肥胖的标准：日常生活中，人们常用体重来衡量一个人的胖瘦。而在医学评估中，目前主要采用体质量指数（BMI）来评估您的重量。

体重指数（BMI）=体重（公斤）÷身高（米）的平方（kg/m²）

例如：一个人的身高为1.75米,体重为70公斤，他的BMI=70÷（1.75×1.75）=22.86。

根据世界卫生组织公布的标准：正常人BMI为18.5～24.9，BMI≥25为超重，BMI≥30为肥胖。

对于不同的人种，同样的BMI可能代表的肥胖程度不一样。我国常用的BMI标准为：正常范围是18.5～23.9，BMI≥24为超重，BMI≥28为肥胖。

BMI考虑了体重和身高两个因素，简单、实用，可以反映全身性超重和肥胖，因此对于一些疾病风险评估时，比单纯的以体重来认定，更具准确性。

有些女性体重和BMI并没有明显超标，但是脂肪都集中在腰腹部，小肚子鼓鼓的。这种“向心性肥胖”的体型，俗称“苹果型体型”，其实对排卵有蛮大影响。

大量的观察数据支持，夫妇双方更多倾向于BMI的一致化，因为夫妇俩长期一起生活，生活方式、饮食结构、运动习惯常常类同。不孕夫妇常常两人都存在体重的问题。

肥胖面临的生育问题——女性

相比于男性，女性更容易积累脂肪，这是由女性的生理结构决定的。

肥胖对女性的影响主要有以下几个方面：

1.生育年龄延迟，怀孕较困难。；

2.胰岛素抵抗，通过促进雄激素升高干扰排卵，引起排卵障碍。

3.影响卵子质量。

4.在卵子的研究显示：肥胖女性使内膜容受性降低。

肥胖面临的生育问题---男性

其实男性也应该多注意自己的身材。过度的肥胖也会让男性生殖健康受到危害。

1.久坐，腹部脂肪堆积，可增加睾丸温度，可能影响精子发生。

2.肥胖男性体内雌激素水平高，干扰下丘脑-垂体-性腺轴，“雄性”不足。

3.动物实验证实，血液中高雌激素水平，影响精子发生。

4.在人类中， BMI过高和中枢性肥胖与精子浓度、精子运动能力降低、及精子形态异常有关。

肥胖对男性及女性生殖系统的影响（+有影响，？不确定）

鼓励每一对超重或肥胖不孕夫妇进行减重：

对于超重女性，减重10%可改善胰岛素抵抗，增加自然妊娠概率和活产率。有研究显示体外受精（IVF）周期中减重超过3kg，有利于获得更多成熟卵子。

同样的，当肥胖男性减重后，精液质量将得到改善。的一项研究表明：随着饮食习惯的改善，腹部脂肪的减少，可降低男性精子碎片指数，改善代谢，较容易使女性配偶获得妊娠。

因此超重或肥胖的不孕夫妇无论是自然妊娠还是IVF助孕，通过双方减重均可以提高受孕率，同时减轻体重还可以减少女性孕期并发症，更有利于生下健康的孩子，远期效果还包括降低并发症：如二型糖尿病、心血管疾病等，终身获益。

为什么要夫妻双方共同减重？

1.夫妻双方有共同的生活环境和行为方式

2.互相鼓励、使得减重计划更加持久

因此我们鼓励并提倡超重或肥胖的不孕夫妻双方共同减重，为了您的好孕和健康加油。
